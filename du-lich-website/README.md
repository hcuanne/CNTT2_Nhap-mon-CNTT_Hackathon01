# Website du lịch
Đây là **website du lịch **, dùng để quản lý sản phẩm và dữ liệu

## Cấu trúc dự án

| Thư mục | Chức năng |
|---|---|
| `docs/` | Chứa tài liệu |
| `media/` | Chứa hình ảnh, logo |
| `data/` | Chứa dữ liệu |
| `logs/` | Chứa nhật ký hệ thống |
| `backup/` | Chứa bản sao lưu |

## Liệt kê dự án

```bash
ls -aR
```
